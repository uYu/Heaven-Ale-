# AI 首轮验证 · 2026-09-16

此文记录上一版困难 AI（现在的 `hard-v1`）。当前版本见 [第二版验证](ai-v2-validation.md)。

原版算法逐字保留在 `src/game/ai.baseline.ts`，SHA-256：

`becf3e0177405aac143e7868dc1286456ee5b843c9d23cf472ba4402c68c7820`

`tests/ai.test.ts` 固定此校验值，同时验证默认入口和显式 baseline 的决策一致性。新增策略放在独立文件，今后调参不要改基线或它的校验值。

## 实现与范围

普通版增强酿酒师门槛、棚屋实际奖励及应急出售判断。困难版包含两回合束搜索、对手按真实座次行动、保留基线回合候选，以及两个公开信息采样牌局的终局复核。各候选使用相同的假设牌堆；任何场景必须全部候选跑完，才参与比较。全程采用真实规则引擎，节点预算为 6500，不修改输入局面。

树搜索只使用当前轮公开市场，跨轮的终局模拟重建未知板块集合并独立洗牌，保持两个时代的顺序。测试验证改变真实未来牌序、开局种子和历史，不影响困难决策。模拟中的其他玩家暂时使用原版策略；面对普通、困难或真人时仍存在预测偏差。

最初仅有局面评估的短搜索未能稳定超过基线，因此当前交付版加入终局复核；下面的数据全部来自加入终局复核后的算法，不混入早期原型数据。

## 对战方法

每局一位待测 AI、三位对照 AI。每个种子轮换全部四个座位，保留原有起始奖励。并列冠军按人数分摊胜场。每个行动执行后检查完整状态不变量，超过 1500 个行动视为异常。每个种子的四个座位有关联，不能当作完全独立样本。

普通对基线与困难对基线的逐局数据分别保存为 `ai-normal-results.txt`、`ai-baseline-results.txt`。困难对普通使用独立的 3000 段种子，不用于调整当前交付参数；完整数据保存在 `ai-hard-vs-normal-results.txt`。

已完成的初步结果（共 36 局新旧对战，全部正常结束）：

| 对战                   | 种子      | 局数 | 分摊胜率 | 待测平均分 | 对照平均分 | 对最强对照平均分差 | 决策中位数 / P95 |
| ---------------------- | --------- | ---: | -------: | ---------: | ---------: | -----------------: | ---------------: |
| 普通对基线             | 2000–2003 |   16 |   43.75% |      22.00 |      15.77 |              -3.75 | 0.034 / 0.890 ms |
| 困难对基线             | 1030–1031 |    8 |   87.50% |      38.88 |      12.79 |             +19.75 | 392.9 / 831.8 ms |
| 困难对普通（独立验证） | 3000–3002 |   12 |   75.00% |      27.33 |      15.61 |              +0.25 | 396.4 / 836.7 ms |

独立验证中困难版赢了 9 / 12 局，但对最强对手的平均分差仅 +0.25：有些胜局差距较小，败局可能差距很大，仍有策略波动。

这是首轮小样本结果，不能据此承诺在其他种子或真人对局中的稳定胜率。脚本中的区间是按种子分组的正态近似，小样本下不可靠。耗时来自本机 Node 运行，部分对战与测试并行，不能当作其他设备或浏览器的性能保证。困难版本批次最慢决策约 1.25 秒。

## 功能验证

- `npm test`：34 项通过，包含原有 20 局基线自对局。
- 新增冻结基线校验、默认路由、决策合法性、确定性、隐藏信息独立性、输入不变、预算退化、终局倍率选择、应急出售、棚屋阶段与完整混合对局测试。

- `npm run build`：类型检查与生产构建通过。
- 浏览器验证：三档设置可切换；独立测试端口中三位困难 AI 均正常购买并继续行动，无控制台错误。原有端口的存档保持原状。

## 复现与扩大样本

```bash
npm run benchmark:ai -- 2 1030 hard-v1 baseline
npm run benchmark:ai -- 4 2000 normal baseline
npm run benchmark:ai -- 3 3000 hard-v1 normal
# 后续扩大验证：使用新的种子，不用它们反复调参
npm run benchmark:ai -- 100 10000 hard normal
```

设置默认困难，可随时选择“基线 · 原版 AI”。难度设置为本次页面会话偏好，刷新后恢复困难；存档依然重放已经提交的动作，不依赖当时使用的 AI 算法。
